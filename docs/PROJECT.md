# Gapir — о проекте (для продолжения работы на любом устройстве)

Обновлено: 17.11.2026, версия 1.7.1. Что менялось по версиям: [CHANGELOG.md](../CHANGELOG.md).

## Что это

Приложение для изучения языков в стиле Duolingo. Ученики — китайцы, живущие в Узбекистане.
- Курс **китайский → русский** (главный сейчас): 4 юнита, 24 урока, по учебникам из папки `методички/`.
- Курс **китайский → узбекский**: 2 юнита.
- Интерфейс на 4 языках: китайский, русский, узбекский (новый алфавит: ö ğ ş ç), английский.
- Раздел **«Квиз»**: учитель на своём сайте создаёт комнату, ученики входят по коду из 6 цифр, пишут имена и отвечают с телефонов. Регистрация не нужна ни учителю, ни ученикам.

## Запуск на новом устройстве

Нужны Node.js 22.13+ и Python 3 (для озвучки).

```bash
git clone https://github.com/xopesa/gapir.git
cd gapir
git checkout feat/cloudflare-duo-lessons
npm install
```

Файл `.env` в git не хранится. Скопируйте `.env.example` в `.env` и заполните `DATABASE_URL` (например `file:./prisma/dev.db`), `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `ADMIN_NAME`. Провайдеры ИИ можно оставить `mock`.

```bash
npm run db:migrate
npm run db:seed
npm run dev
```

Сайт откроется на http://localhost:3000, сайт учителя — на http://teacher.localhost:3000 (тот же сервер, вход не нужен). Проверки перед сохранением: `npm test`, `npx tsc --noEmit`, `npm run lint`.

Для выкладки нужен вход в Cloudflare: `npx wrangler login` (аккаунт владельца проекта).

## Типы заданий

Хранятся в базе как 4 типа, варианты задаются полями:
- `MULTIPLE_CHOICE` — выбор ответа; с `listen: true` — задание на слух (виден только динамик).
- `MATCHING` — соединить пары.
- `ARRANGE_WORDS` — собрать фразу из слов.
- `TRANSLATE` — ответ из плиток (`tiles`); с `say: true` — «скажи вслух» (микрофон).
- У любого задания может быть `teach` — короткое объяснение перед ним.

Клавиатурного ввода в уроках нет и добавлять его не нужно: либо плитки, либо выбор, либо голос.

## Квиз и сайт учителя

- Учитель: сайт учителя (вход не нужен, при первом заходе создаётся гостевой вход) → готовый квиз юнита, «Новый квиз» или «Собрать из уроков» → «Создать комнату» → на экране адрес и код из 6 цифр → когда ученики вошли, «Начать».
- Готовые квизы нигде не хранятся: при запуске игры берутся 20 случайных вопросов из заданий «выбери ответ» и «соедини пары» этого юнита. Новый юнит с 10 и более такими заданиями получает готовый квиз сам.
- Ученик: Gapir → «Квиз» → код и имя. Работает и в приложении Android: это тот же сайт.
- Квизы и комнаты принадлежат входу учителя. У гостя это вход в его браузере (30 дней), поэтому свои квизы гостя видны только в этом браузере. Роль TEACHER в базе осталась с версии 1.5.0, но ничего не даёт.
- Кабинет учителя работает только на адресе учителя. Какой адрес считается учительским, задают `TEACHER_ORIGIN` и `LEARNER_ORIGIN` в `wrangler.jsonc`.
- Игра без постоянного соединения: экраны раз в 1–2 секунды запрашивают состояние. Правильный ответ уходит на телефоны только после закрытия вопроса.
- На сайте (база D1) в одном запросе нельзя передать больше ~100 значений, поэтому уроки для квиза читаются по одному (`questionsFromLessons` в `quiz-service.ts`). Локальная база этого ограничения не имеет: такие места проверять на `npx wrangler dev`.
- Квизы и игры хранятся в таблицах `Quiz…`. Их можно удалять: с уроками и прогрессом учеников они не связаны.

## Как выложить обновление

```bash
npm test
npm run db:seed
npx tsx scripts/generate-audio.ts
node scripts/export-content-sql.mjs > .open-next/content.sql
npx wrangler d1 execute gapir-db --remote --file .open-next/content.sql --yes
npm run cf:build
npx opennextjs-cloudflare deploy
```

Если в обновлении есть новая миграция базы (новые файлы в `migrations/`), перед `cf:build` применить её: `npm run db:migrate:d1:remote`.
Worker сайта учителя выкладывается отдельно и редко — только когда меняется `workers/teacher/`: `npx wrangler deploy --config workers/teacher/wrangler.jsonc`.

Правила:
- Перед выкладкой поднять версию в `package.json` и дописать `CHANGELOG.md`.
- В базу сайта уроки только добавляются и обновляются. **Никогда не удалять уроки в D1**: вместе с уроком стирается прогресс учеников.
- Если менялись только код и дизайн, шаги с `db:seed`, `export-content-sql` и `d1 execute` не нужны.
- После выкладки записать в `CHANGELOG.md` номер «Current Version ID» из вывода deploy.

## Приложение Android

- Это оболочка: открывает сайт с адреса `/start` (гостевой вход без пароля). Уроки, дизайн и исправления приходят с сайта сами, пересобирать приложение для этого не нужно.
- Пересобирать нужно, когда меняется сама оболочка: иконка, разрешения (микрофон), версия.
- Сборка запускается сама при отправке на GitHub изменений в `package.json` (новая версия), `capacitor.config.ts`, `mobile/` или в самом сценарии сборки. Вручную: GitHub → Actions → «Android APK» → Run workflow. Готовый файл `Gapir-v<версия>.apk` лежит в артефактах запуска.
- Версия приложения = версия сайта на момент сборки. Приложение сообщает её сайту, и она видна в профиле («приложение 1.1.0»). Сборка от 11.11.2026 показывает «приложение 1.0».
