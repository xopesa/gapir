# Gapir sound assets

Place the production MP3 files in this directory using these exact names:

- `button-tap.mp3`
- `correct-answer.mp3`
- `wrong-answer.mp3`
- `lesson-complete.mp3`
- `xp-reward.mp3`
- `streak-reward.mp3`
- `purchase.mp3`
- `notification.mp3`

Until an asset is added, the sound manager uses a short Web Audio tone and never blocks the interface.
