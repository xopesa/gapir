# 🧠 Главный принцип разработки

Каждый новый экран должен вызывать ощущение:

> **"Этим приложением хочется пользоваться каждый день."**

## 🚀 Следующий шаг

Теперь переходим к одному из самых важных элементов — **логотипу**.

Я предлагаю разработать **3 совершенно разные концепции** (не просто разные цвета):

1. **Speech Bubble** — облачко речи с интегрированной буквой **G**.
2. **Узбекский орнамент** — минималистичный символ, вдохновлённый национальными узорами, который легко узнаётся даже без текста.
3. **Современный монограмный знак** — лаконичная геометрическая **G**, которую можно использовать как иконку приложения, favicon и элемент мерча.

После выбора одной концепции уже будем прорабатывать финальный логотип, адаптации для светлой и тёмной темы, иконку приложения и полный фирменный стиль.
