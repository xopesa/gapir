# Gapir

Gapir — адаптивное Web-приложение для изучения живого узбекского языка. Первый этап проекта сфокусирован на продуктовой архитектуре, дизайн-системе и пяти основных экранах. Все данные сейчас являются демонстрационными; прогресс, покупки и тестовая сессия сохраняются локально в браузере.

Тестовый доступ: логин `Test`, пароль `2804meili`. Это mock-вход без backend и серверной проверки личности.

## Стек

- Next.js 16 с App Router, React 19 и TypeScript strict
- Tailwind CSS 4 и централизованные CSS design tokens
- Framer Motion для мягких spring-анимаций
- Zustand с persist middleware для локального состояния
- TanStack Query как готовый слой для будущего API
- React Hook Form и Zod для типобезопасных форм
- Phosphor Icons
- clsx и tailwind-merge

## Запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run lint
npm run build
```

## Основные маршруты

- `/` — обучение и дорожка уроков
- `/practice` — режимы практики
- `/leagues` — недельная лига
- `/shop` — магазин за GapCoin
- `/profile` — профиль, достижения и настройки

## Структура

```text
app/                  App Router, маршруты, layout и глобальные стили
src/components/ui/    Переиспользуемые UI-компоненты
src/components/layout/Адаптивная оболочка и навигация
src/features/         Экраны, разделённые по продуктовым функциям
src/mocks/            Демонстрационные данные
src/stores/           Независимое Zustand-состояние
src/lib/              Query Provider и общие утилиты
src/types/            Доменные типы
public/               Логотип и social preview
```

## Архитектурное направление

UI, доменные типы, mock-данные и состояние разделены, чтобы будущая мобильная версия могла переиспользовать бизнес-правила без зависимости от Web-разметки. Следующий этап — вынести API-контракты в отдельный пакет, заменить mock query functions реальными endpoints, подключить авторизацию и серверную синхронизацию. После стабилизации контрактов общие типы, валидация и store actions могут быть использованы в React Native.
